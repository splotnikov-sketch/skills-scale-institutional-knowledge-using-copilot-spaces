## OctoAcme Project Management Docs

OctoAcme takes a customer-first, iterative, data-informed approach with clear ownership. Projects move from initiation—validating the need, aligning stakeholders, and setting success measures—through planning, where teams prioritize and estimate work, define acceptance criteria and milestones, and identify dependencies. During execution, teams deliver and test small increments while tracking progress and risks; releases are verified and backed by rollback plans, and retrospectives turn lessons into owned improvement actions.

The Project Manager coordinates delivery, risks, and communications with the Product Manager, developers, QA, and stakeholders. Regular standups, delivery syncs, demos, and stakeholder updates keep work aligned; risks and blockers are tracked and escalated through defined paths. Quality is supported by unit and applicable integration tests, CI tests and linting, security scans, code review, and smoke tests for critical flows and releases.
